OTP Bridge

Fills text-message codes from the OTP Bridge app on this PC into login forms.

  1. Right-click the OTP Bridge tray icon and choose Copy browser pairing key (or run otp-bridge pair-extension).
  2. Paste the key below and click Save.
Only this browser and the OTP Bridge app know it. It never leaves this PC.
Change it only if you changed port in OTP Bridge's settings.
